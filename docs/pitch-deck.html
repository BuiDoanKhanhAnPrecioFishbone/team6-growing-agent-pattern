The Growing-Agent Pattern — a reusable .NET harness on Azure AI Foundry. No GPU, no fine-tuning. Every claim in this deck is a program you can run.

01 The problem

Frontier models are expensive — and flat-expensive forever.

The 10,000th call costs the same as the first. Cheap models are affordable but weak. And Omnia doesn't run one agent — it runs many: screen, draft, review, summarize. Cost and quality both matter, at scale.

02 The bet

Don't reach for a bigger model. Build a harness around a cheap one.

An agent is a policy in a deterministic environment, judged by one reward that gates it now — and could train it later. It improves two ways:

Within a run inference-time

sample several drafts, ground with tools, self-verify, and let the reward keep the best.

Run-to-run memory

every fixed mistake becomes a lesson the next run recalls. The pipeline compounds — and cost drops.

03 What we built

One reward. One loop. One contract. Any domain.

generate ×N→ reward→ retrieve lesson→ revise→ keep best→ learn

Amplifier

best-of-N · web-search · self-verify · escalation — a weak model, lifted.

Memory ×2

self-curating lessons (trust, decay, conflict) + short-term context compaction.

Tools

web_search, memory_search, vision, and any MCP server.

Swap the reward → the same harness grows a value-investing agent, a code agent, or a UI-from-design agent. Proven across four.
