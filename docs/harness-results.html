The bet

the whole idea in three lines

An agent is a policy

  • It runs in a deterministic environment, judged by one reward that gates it now and could train it later — the reward is the only authority on what's correct.

It improves two ways

  • Within a run — sample, verify, revise against the reward.
  • Run-to-run — every fixed mistake becomes a lesson the next run recalls. The pipeline compounds.

Domain-agnostic

  • The loop, memory and tools never mention finance. Swap the reward and the same harness grows a code agent (reward = unit tests pass).
generate ×N→ evaluate · reward→ retrieve lesson→ revise→ keep best→ write lesson

The fast loop. Best-of-N, grounding, self-verify and escalation all hang off it — off by default, so the pipeline still runs fully offline.

What the harness gives a weak model

inference-time compute, not a bigger model

The amplifier 4 levers

  • Best-of-N — draw N drafts, keep the one the reward scores highest AGENT_SAMPLES
  • Web-search grounding — look facts up instead of guessing (keyless Wikipedia)
  • Self-verify — an LLM critic catches soft errors the reward can't AGENT_SELF_VERIFY
  • Escalation — call a bigger model only on hard cases AGENT_LLM_MODEL_STRONG

Memory, two timescales keep / let go

  • Long-term lessons — semantic retrieval + LLM recall; trust earned Provisional→Verified
  • Self-curating — stale lessons decay, the least-valuable are evicted, contradictions demote a rule
  • Short-term context — a long session is compacted to a token budget (recent sharp, old summarized)

Tools & MCP extensible

  • Built-ins — web_search, memory_search, deterministic compute
  • Any MCP server — a real stdio JSON-RPC client wraps each tool as one the agent can call
  • Safe by default — read-only tools run free; mutating ones are gated

Why context management matters

truncate“target 8%, risk moderate” ✗
compact“target 12%, risk LOW” ✓

At the same budget a naive window didn't just forget the client mandate — it confabulated a plausible wrong one. Compaction's summary kept the real fact.

Why grounding matters

bare“As of 2024, Warren Buffett is CEO” ✗
+web“Greg Abel” ✓

The model was confidently wrong about a post-training-cutoff fact. It can't know which of its facts are stale — grounding is cheap insurance that fixed exactly the one it missed.

Run it yourself

offline needs nothing; live needs one Foundry deployment

# the compounding pipeline — offline, deterministic (run 1: 12 iters → run 2: 6)
dotnet run --project orchestrator -- --fresh

# capability proofs — offline
dotnet run --project mcptest    # 13 real MCP tools (needs node)
dotnet run --project memlife    # memory lifecycle — 7/7
dotnet run --project ctxtest    # context management — 11/11

# live — set AGENT_LLM_* to your Foundry gpt-4.1-mini first
dotnet run --project ampeval    # grounding: bare 5/6 → +web 6/6
dotnet run --project ctxdemo    # context: compaction recalls, truncation forgets
